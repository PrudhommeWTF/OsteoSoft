Import Doctolib → OsteoSoft

Paramètres de connexion à votre installation OsteoSoft

Adresse où répond l'API OsteoSoft (le serveur Node/Express). En développement il s'agit généralement de http://localhost:4199. Pour une installation hébergée, saisissez l'URL complète (ex. https://osteosoft.mon-cabinet.fr).

Comment ça marche ?

  1. Connectez-vous à OsteoSoft dans ce navigateur (onglet ouvert ou récent).
  2. Ouvrez la fiche d'un rendez-vous sur pro.doctolib.fr.
  3. Cliquez sur le bouton « Ajouter à OsteoSoft » en bas à droite.
  4. Vérifiez les informations, choisissez le patient, puis confirmez l'import.
